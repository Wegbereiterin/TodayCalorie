# TodayCalorie

## 프로젝트 개요

YOLOv8 모델을 활용하여 음식을 인식하고 칼로리를 예측하며, 개인의 식단을 기록하고 관리할 수 있는 iOS 앱입니다.
음식 이미지를 촬영하거나 등록하여 칼로리를 기록할 수 있으며, SNS 기능을 통해 다른 사용자와 자신의 식단 기록을 공유하고 소통할 수 있습니다.

## 주요 기능

- 회원가입 및 로그인
  Firebase를 활용해서 간단하고 안전한 인증시스템을 구현했습니다.
- 식사 기록 및 칼로리 확인
  하루동안 섭취한 총 칼로리를 한눈에 확인할 수 있습니다. 기록한 식사는 캘린더에서 날짜별로 조회가 가능하도록 하였습니다.
- 음식 객체 감지 및 칼로리 예측
  YOLOv8 모델을 통해 음식 객체를 인식하고, 음식별 칼로리를 계산합니다.
  추가로 사용자가 얼마나 먹었는지에 따라 식사량을 선택할 수 있도록 하였습니다.
- 부적절 컨텐츠 감지
  부적절한 이미지(손가락욕)를 감지하고 필터링하여 건전한 콘텐츠 공유를 보장하였습니다.
- SNS 기능
  식사를 기록할 때, 해당 글을 다른 사용자에게 공유할 것인지 선택할 수 있습니다.
  다른 사용자의 식단 기록을 확인하고 좋아요 및 댓글을 통해 소통할 수 있습니다.
- 설정
  로그아웃 및 회원 탈퇴 기능을 제공하였습니다.

## 사용 기술 및 개발 환경

Frontend: Swift, UIKit
Backend: Firebase Authentication, Firestore
Object Detection: YOLOv8s
개발환경: Xcode, GoogleColab

## 프로젝트 구조

프론트엔드 구성:
  - UIKit을 활용한 사용자 친화적인 UI 설계
  - iOS에서 실시간 객체 감지 및 데이터 처리

백엔드 구성:
  - Firebase 기반 회원가입, 로그인 및 데이터 관리
  - Firestore를 활용한 사용자 기록 저장
